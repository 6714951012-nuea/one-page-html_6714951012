CNN — Convolutional Neural Network

ดู Convolution (kernel สไลด์บนภาพ) และ Max Pooling (ลดขนาดภาพ) แบบทีละขั้นตอน

อินพุต 7×7

→

Feature Map 5×5 (Conv 3×3 + ReLU)

→

Max Pooling 2×2 → 2×2

Kernel 3×3

🎨 คลิก/ลากบนภาพซ้ายเพื่อวาดเองได้
ตำแหน่ง kernel: (0,0)
ขนาดอินพุต→FM→Pool: 7×7 → 5×5 → 2×2

หลักการทำงาน

Convolution: kernel ขนาด 3×3 สไลด์ (stride 1) ทับบนภาพ คำนวณผลรวมแบบ (ภาพ × kernel) ทีละตำแหน่ง ได้ Feature Map ที่เล็กลง (7−3+1 = 5) จากนั้นผ่าน ReLU max(0, x) เพื่อตัดค่าลบ
Max Pooling: แบ่ง Feature Map เป็นบล็อก 2×2 แล้วเก็บค่าที่มากที่สุด ลดขนาดลงครึ่งหนึ่ง (5×5 → 2×2) ทำให้โมเดลทนต่อการเลื่อนของวัตถุและลดจำนวนพารามิเตอร์
