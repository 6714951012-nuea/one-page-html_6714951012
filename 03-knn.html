k-Nearest Neighbors (kNN)

จำแนกจุดใหม่โดยดู k เพื่อนบ้านที่ใกล้ที่สุด แล้วใช้เสียงส่วนใหญ่ (Majority Vote) กำหนดคลาส

💡 เลื่อนเมาส์เพื่อทดสอบจุดใหม่ • คลิกเพื่อเพิ่มจุด
จุดทดสอบถูกจัดเป็น: —
Class 0 / Class 1: 0 / 0
ระยะทางถึงเพื่อนบ้านที่ k: —
จำนวนจุด: 0

หลักการทำงาน

kNN เป็นอัลกอริทึมแบบ Instance-based / Lazy learning คือไม่มีการฝึก แต่จำข้อมูลทั้งหมดไว้ ตอนทำนายจะคำนวณระยะทาง (Euclidean) จากจุดใหม่ไปยังทุกจุด แล้วเลือก k จุดที่ใกล้ที่สุด คลาสที่โหวตได้เสียงข้างมากคือคำตอบ พื้นหลังแสดงขอบเขตการตัดสินใจ (Decision Boundary) ที่เปลี่ยนไปตามค่า k
