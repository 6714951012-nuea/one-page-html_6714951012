หลักการทำงาน

MLP ประกอบด้วยชั้น Input → Hidden (sigmoid) → Output (sigmoid) ค่าจะไหลไปข้างหน้า (Forward Propagation) คำนวณ error แล้วส่งย้อนกลับ (Backpropagation) เพื่อปรับน้ำหนักด้วยกฎลูกโซ่ (Chain Rule) ทำซ้ำจนโมเดลจำลอง XOR ได้ ฟังก์ชัน XOR ไม่สามารถเรียนรู้ได้ด้วยเส้นตรงเส้นเดียว (Perceptron เดี่ยว) จึงต้องมี hidden layer
